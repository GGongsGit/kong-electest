이 프로그램은 전기기능사 실기 시험에 나오는 시퀀스 제어 회로를, 종이 대신 화면에서 그려보고 실제로 눌러가며 연습할 수 있게 만든 도구입니다. 전원 · 접점 · 코일 · 램프 · 전동기 같은 부품을 가져다 놓고 선으로 연결한 뒤, 테스트 모드로 진짜 눌러보거나 회로 분석으로 자동 점검을 받을 수 있습니다. 아래 순서대로 한 번씩 따라 해 보면 전체 기능을 익힐 수 있습니다.

시작하며 — 이 프로그램으로 무엇을 하나요

전기기능사 실기는 주어진 회로도를 보고 제어반에 부품을 배치하고, 배선을 연결하고, 정상적으로 동작하는지 확인하는 시험입니다. 이 프로그램은 그 과정을 컴퓨터 화면에서 미리 연습해 볼 수 있게 세 가지를 제공합니다.

  • 회로 그리기 — 접점·코일·램프 같은 부품을 놓고 선으로 이어 시퀀스 회로를 완성합니다.
  • 실제 동작 확인 — 완성한 회로를 진짜로 눌러보면서, 원하는 순서대로 램프가 켜지고 전동기가 도는지 확인합니다.
  • 기출 문제 연습 — 미리 등록된 📋 공개 문제를 불러와, 같은 방식으로 연습합니다.

Tip. 처음이라면 테스트 모드 절을 먼저 읽고, 아주 간단한 램프 하나짜리 회로로 손에 익힌 뒤 본격적인 문제로 넘어가는 것을 추천합니다.

화면 구성

화면은 크게 다섯 영역으로 나뉩니다. 아래 그림에서 각 영역의 이름과 역할을 먼저 익혀두면, 이후 설명을 따라오기 훨씬 쉽습니다.

① 상단 도구 모음

🔌 배선 ⚪ 기본색 🧵 배관 ↻ 회전 ▦ 직각선: ON 📋 공개 문제 💾 SVG 내보내기 📄 JSON 저장 🆕 신규 생성 📂 불러오기 📘 매뉴얼 처럼, 회로 편집에 필요한 주요 기능이 버튼으로 모여 있습니다.

② 부품 상자

접점(범용)·스위치/버튼·보호기기·계전기/타이머·표시등·전동기·배선·테스터기 같은 카테고리별로 부품이 정리되어 있습니다. 카테고리 제목을 누르면 접고 펼칠 수 있습니다.

배선 카테고리에는 전원·공통·노드 같은 기본 요소뿐 아니라 TB 단자대 · 릴레이/타이머 소켓 · MCCB/FUSE 소켓 · 설치판 · 마스킹 테이프 · 분필/자/스트리퍼 같은 도구 · 🧲 단자 표시 자석이 들어 있습니다. 부품 상자와 속성창 사이의 경계선을 끌면 폭을 조절할 수 있습니다.

③ 작업 화면

실제로 회로를 그리는 공간입니다. 점선 격자가 표시되어 부품을 가지런히 놓기 쉽습니다.

④ 속성창

지금 선택한 부품의 이름표, 색상, 극수, 시간 같은 세부 값을 바꾸는 곳입니다. ◨ 속성창 숨기기로 필요할 때만 펼칠 수 있습니다.

⑤ 테스트 바

🔌 결선 체크, 🧩 기기 배치, 🔎 회로 분석 시작, ▶ 테스트 모드 시작, 🔄 초기화 버튼이 있는 하단 영역입니다. 🔌 결선 체크는 제어판 배치/결선 화면에서만 쓸 수 있고, 🧩 기기 배치는 현재 개발 중이라 누르면 안내 창만 뜹니다.

안내·경고 메시지는 화면 가운데에 뜨는 알림 창으로 나타나며, 확인 버튼이나 Esc, 창 밖 클릭으로 닫을 수 있습니다.

부품 다루기

놓기 · 선택 · 이동

  1. 왼쪽 부품 상자에서 원하는 부품을 마우스로 눌러 작업 화면으로 끌어다 놓습니다 (드래그 앤 드롭).
  2. 놓인 부품을 한 번 클릭하면 선택되고, 오른쪽 속성창에 그 부품의 정보가 나타납니다.
  3. 선택한 부품을 마우스로 끌면 이동합니다. ▦ 직각선: ON 상태면 격자에 맞춰 붙습니다. (옆의 숫자 칸에서 격자 간격을 바꿀 수 있습니다.)
  4. 부품이 없는 빈 곳에서 마우스를 드래그하면, 사각형 안에 들어온 부품이 한 번에 여러 개 선택됩니다.
  5. Ctrl 또는 Shift 키를 누른 채 다른 부품을 클릭하면, 이미 선택한 것은 그대로 두고 하나씩 선택을 추가·해제(다중 선택)할 수 있습니다.

회전 · 삭제 · 되돌리기

  • 부품을 선택한 뒤 상단 ↻ 회전 버튼으로 방향을 바꿉니다.
  • 부품을 선택하고 Delete 또는 Backspace 키로 지웁니다.
  • 실수했을 땐 Ctrl + Z로 바로 전 상태로 되돌립니다.
  • 선택한 부품은 Ctrl + C로 복사, Ctrl + V로 붙여넣습니다.
  • Ctrl + 마우스 휠로 작업 화면을 확대·축소합니다.

여러 부품을 한꺼번에 선택했다면, 상단 도구 모음의 정렬 메뉴로 좌/우/가운데/위/아래를 깔끔하게 맞출 수 있습니다.

배선 그리기

  1. 상단 🔌 배선 버튼을 눌러 배선 모드로 바꿉니다.
  2. 필요하다면 먼저 옆의 색 드롭다운(⚪ 기본색·갈색·흑색·회색·녹색·황색)에서 전선 색을 골라둡니다. 실제 결선처럼 색깔로 회로를 구분해 연결할 수 있습니다.
  3. 연결하려는 부품의 단자(끝쪽 동그라미)를 클릭하고, 이어서 다른 부품의 단자를 클릭합니다. ▦ 직각선: ON 상태면 두 점 사이가 자동으로 직각으로 꺾인 선으로 이어지고, OFF면 곧은 선으로 이어집니다.
  4. 단자와 단자 사이 빈 곳을 클릭하면 경유점이 찍혀, 원하는 경로로 선을 돌려 그릴 수 있습니다.
  5. 배선 모드를 끝내려면 다시 🔌 배선을 누르거나 Esc를 누릅니다.

그린 배선 고치기

  • 이미 그린 배선을 클릭하면 하늘색의 약간 굵은 선으로 바뀌며 선택되고, 선 위에 꺾임점·접속점이 함께 표시됩니다. 선택을 해제하면 원래 색으로 돌아갑니다. (배선 색이 주황 계열이어도 선택된 것을 알아보기 쉽도록 하늘색을 씁니다.)
  • 선택한 배선은 속성창에서 색을 바꾸거나 Delete로 지울 수 있습니다.
  • 선 위의 점을 드래그하면 꺾이는 위치를 원하는 대로 옮길 수 있습니다.
  • 한 단자에 배선이 여러 개 겹쳐 있어 하나만 집기 어렵다면, 겹친 지점의 점을 반복해서 클릭하세요. 클릭할 때마다 겹친 배선을 하나씩 돌아가며 선택합니다.

배관 · 기구 배치 연습

전선 회로뿐 아니라, 실제 시험처럼 설치판 위에 기구를 배치하고 배관으로 연결하는 연습도 할 수 있습니다.

설치판 놓기

  • 부품 상자에서 설치판을 놓으면 나무 작업판처럼 표시됩니다.
  • 설치판 우하단의 자물쇠 아이콘을 누르면 그 자리에 고정(잠금)하거나 풀 수 있습니다. 다른 부품을 그 위에 배치할 때 실수로 판이 같이 움직이지 않도록 잠가두면 편리합니다.

배관 그리기

  1. 상단 🧵 배관 버튼을 누르고, 옆의 드롭다운에서 PE전선관·플렉시블·케이블 중 종류를 고릅니다.
  2. 배선을 그릴 때와 같은 방식으로, 지나갈 지점을 순서대로 클릭해 배관 경로를 그립니다.

기구 · 도구

부품 상자에서 정션 박스, PE전선관용·플렉시블용 커넥터, 새들(중자/소자) 같은 실제 배관 자재와, 분필 · 자 · 와이어 스트리퍼 · 스프링 벤더 같은 도구 아이콘도 배치할 수 있습니다. 마스킹 테이프 부품으로는 기구 옆에 이름표를 붙이는 연습도 가능합니다.

분필로 마킹선 긋기

설치판 위에 기구를 놓기 전에 치수를 표시해 두는 연습용 기능입니다. 작업 화면에 놓인 분필 도구를 더블클릭하면 마킹 모드가 켜지고, 지점을 순서대로 클릭하다가 더블클릭으로 선을 마칩니다. Esc나 도구의 종료 아이콘으로 마킹 모드를 끝냅니다. 마킹선은 얇은 흰색 점선으로 표시되며 전기적 연결과는 무관하고, 클릭해서 선택·이동·삭제할 수 있습니다.

제어판 결선 · 결선 체크

회로도를 보고 설치판 위의 소켓·단자대에 직접 배선하는 연습입니다. 📋 공개 문제의 제어판 배치/결선을 열면 연습 화면이 나타납니다.

번호가 맞는 자리에 배선하기

  • 릴레이·타이머·EOCR 소켓은 핀 번호(예: X1의 1~8번)로, 버튼·리밋스위치·램프처럼 현장에 나가는 기기는 단자대(TB)에 붙은 마스킹 테이프의 글자(예: PB1의 A·C)로 자리를 구분합니다.
  • 회로도(회로 및 NO 부여)에서 같은 번호끼리 이어져 있으면, 제어판에서도 그 핀끼리 배선으로 이어야 합니다.

🔌 결선 체크

배선을 다 했으면 아래쪽 🔌 결선 체크를 누릅니다. 같은 공개문제의 회로도를 정답으로 삼아 지금 제어판의 배선을 점검해 줍니다.

  • ✕ 끊김 — 회로도에서는 이어져 있는데 제어판에서는 이어지지 않은 곳. 화면에는 주황색 동그라미로 표시됩니다.
  • ⚡ 합선 위험 — 이어지면 안 되는 두 곳이 이어져 있는 경우. 화면에는 빨간색 동그라미로 표시됩니다.
  • ❔ 자리 없음 — 해당 번호의 소켓 핀이나 단자대 자리를 제어판에서 찾지 못한 경우.
  • 문제가 없으면 ✅ 결선이 회로도와 일치한다고 알려 줍니다. 결과 창은 제목을 끌어 옮길 수 있습니다.

알아둘 점. 결선 체크는 버튼·스위치·보호 접점을 "눌린/닫힌 상태"로 보지 않고, 접점 양쪽을 각각 따로 배선해야 하는 자리로 봅니다. 그래서 정지버튼(PB0) 같은 접점의 두 단자를 같은 단자대 위의 점퍼선으로 서로 이어 버리면, 접점을 건너뛴 합선으로 보고 연쇄적으로 많은 경고가 뜹니다. 경고가 많다면 가장 먼저 같은 단자대(TB) 안에서 극과 극을 잇는 짧은 선이 없는지 확인해 보세요.

🧲 단자 표시 자석

결선해야 할 단자를 눈에 띄게 표시해 두는 용도입니다. 배선 직전에 "여기를 이어야 한다"고 메모해 두거나, 헷갈리는 단자를 따로 표시할 때 씁니다.

  1. 부품 상자의 배선 카테고리 맨 위 단자 표시 자석을 끌어, 결선할 단자 위에 올려 둡니다. 빨간 점선 고리와 자석 아이콘이 깜빡이며 표시됩니다.
  2. 자석은 표시일 뿐 전기적 연결에는 아무 영향이 없고, 배선 모드·벨테스터기 모드에서는 클릭이 자석을 통과해 밑에 있는 단자로 그대로 들어갑니다. 즉 자석을 올려둔 단자에도 바로 배선할 수 있습니다.
  3. 다 쓰고 나면 같은 카테고리의 🧲 표시 자석 전체 지우기 버튼으로 캔버스의 자석을 한 번에 지웁니다. 실수했다면 Ctrl + Z로 되돌릴 수 있습니다.

🧩 기기 배치 (개발 중)

회로도를 기준으로 소켓과 단자대를 자동 배치하는 기능으로, 아직 개발 중입니다. 버튼은 흐리게 표시되어 있고 누르면 "현재 개발 중입니다" 안내만 나옵니다. 지금은 부품 상자에서 소켓과 단자대를 직접 끌어다 놓아 주세요.

테스트 모드로 실제 동작 확인하기

회로를 다 그렸다면, 화면 아래 ▶ 테스트 모드 시작을 눌러 진짜로 눌러볼 수 있는 모드로 바꿉니다.

  1. 테스트 모드에서는 부품을 클릭해 접점을 열고 닫을 수 있습니다.
  2. 눌러야만 붙는 버튼(예: PB1, PB0 같은 모멘터리 버튼)은 마우스 버튼을 누르고 있는 동안만 붙고, 손을 떼면 원래 상태로 돌아갑니다.
  3. 코일이나 램프가 켜지려면, 그 양쪽 단자가 각각 서로 다른 전원/공통 부품까지 끊기지 않고 이어져야 합니다. (전원↔전원 연결도 가능합니다.)
  4. 잘 안 켜지면, 배선이 끊긴 곳이 있는지, 접점이 열려 있지는 않은지, 전원·공통 부품이 2개 이상인지 확인합니다.

🔄 초기화를 누르면 모든 접점·전원 상태가 처음으로 돌아갑니다. 다시 편집하고 싶으면 ■ 테스트 종료 버튼으로 편집 모드로 돌아갑니다.

벨테스터기로 결선 확인하기

제어판처럼 실제로 전원을 넣어볼 수 없는 화면에서, 두 지점이 배선으로 이어져 있는지만 빠르게 확인하는 도구입니다. 부품 상자 맨 아래 테스터기 카테고리의 벨테스터기 (결선 테스트)를 눌러 켜고(다시 누르면 꺼짐), 확인하려는 두 지점을 순서대로 클릭하면 이어져 있는지 알려 줍니다. 전원 인가 여부와 상관없이 배선과 닫힌 접점만으로 판정합니다.

회로 분석 — 자동으로 눌러서 점검하기

🔎 회로 분석 시작을 누르면, 프로그램이 회로 안의 버튼·리밋스위치 등을 정상적인 순서로 알아서 눌러보면서 어떤 코일·램프·전동기가 언제 켜지고 꺼지는지 대신 확인해 줍니다. 직접 하나하나 눌러보기 번거로울 때, 회로가 의도대로 동작하는지 빠르게 훑어보는 용도입니다.

  • 결과는 회로 분석 창에 1. PB1 누름 → X1 여자, WL 점등처럼 단계별 기록으로 나타납니다.
  • 타이머(On-delay 등)가 걸린 회로는 실제 설정된 시간만큼 진짜로 기다린 뒤 결과를 보여줍니다. 여러 초가 걸릴 수 있습니다.
  • EOCR·THR처럼 고장을 감지하는 보호용 접점은 정상 동작을 확인하는 게 목적이라 자동으로 누르지 않습니다.
  • 분석 창의 제목 부분을 드래그하면 원하는 위치로 옮길 수 있고, 오른쪽 아래 모서리를 끌면 크기를 바꿀 수 있습니다.

분석 창이 떠 있는 동안에도 뒤쪽 회로는 그대로 클릭할 수 있습니다. 창을 옆으로 옮겨두고, 분석 기록과 비교하며 직접 접점을 눌러보면 이해가 더 빠릅니다.

공개 문제로 연습하기

상단 📋 공개 문제 버튼을 누르면 문제 목록 화면이 열립니다. 각 칸이 문제 하나에 해당합니다.

문제 등록하기

문제 칸의 설정 버튼으로, 그 문제에 필요한 파일들을 하나씩 올려둡니다.

  • 회로 JSON — 회로 및 NO 부여 연습용 배치 파일
  • 제어판 배치 JSON — 제어판 배치/결선 연습용 배치 파일
  • 배관 배치 JSON — 배관 및 기구 배치 연습용 배치 파일
  • 동작 방식 설명 텍스트 — 이 문제가 어떻게 동작해야 하는지 적힌 글

문제로 연습하기

  1. 회로 및 NO 부여 / 제어판 배치/결선 / 배관 및 기구 배치 버튼을 누르면, 그 배치가 지금 작업 화면으로 불러와져 테스트 모드나 회로 분석으로 바로 연습할 수 있습니다. 제어판 배치/결선 화면에서는 결선 체크로 배선이 회로도와 맞는지 확인할 수 있습니다.
  2. 버튼 옆의 이미지 버튼을 누르면, 지금 화면을 바꾸지 않고도 그 배치를 흰 배경 그림으로 새 창에 띄워 미리 볼 수 있습니다.
  3. 동작 방식 조회를 누르면 문제의 동작 설명 글을 볼 수 있습니다. 이 창도 회로 분석 창처럼 옮기거나 크기를 바꿀 수 있어, 옆에 띄워두고 회로와 비교하며 보기 좋습니다.

연습을 시작하면 화면 위쪽에 공개문제 N 서브 메뉴 막대가 나타나, 같은 문제의 다른 배치로 빠르게 옮겨가거나 연습을 마칠 수 있습니다.

Q결선 체크에서 "합선 위험" 경고가 잔뜩 떠요.

정지버튼(PB0)처럼 접점이 있는 기기의 두 단자가 단자대 위 점퍼선으로 직접 이어져 있으면, 접점을 건너뛴 합선으로 판정되어 이어진 모든 곳에 연쇄적으로 경고가 뜹니다. 같은 TB 안에서 극과 극을 잇는 짧은 선을 찾아 지우면 대부분 사라집니다. 자세한 내용은 제어판 결선 · 결선 체크를 보세요.
